## Open-Source Contributions

Contributing to **[imox2/money-matters](https://github.com/imox2/money-matters)** through bug fixes, regression tests, and code reviews.

### [Fix: Ignore Last-Modified-only evidence manifest churn — PR #1664](https://github.com/imox2/money-matters/pull/1664)

- Fixed evidence-manifest churn when an HTTP `Last-Modified` header changes but the downloaded PDF content remains identical.
- Added regression coverage proving identical PDF bytes keep the manifest unchanged while genuinely changed PDF bytes still create a new content version.
- The maintainer reproduced the Axis Scapia case, confirmed the fix works, and thanked me for the contribution.
- **Status:** Merged into `main`.

### [Guest-charge state: explicit lounge guest-fee modelling — PR #1739](https://github.com/imox2/money-matters/pull/1739)

- Contributed to explicit guest-charge-state modelling so zero complimentary visits are not incorrectly interpreted as proof of paid access.
- Added clear states for documented fees, unestablished guest entitlements, and unknown status, with validation and regression coverage.
- **Status:** Merged into `main`. Publishing these values to live pages requires a separate reviewed release.
